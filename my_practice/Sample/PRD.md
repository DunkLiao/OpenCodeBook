## 1. 專案背景與目標

### 1.1 背景

使用者在日常工作時，經常需要切換視窗才能取得少量高頻資訊：現在幾點、常用網站入口、
RSS 最新標題、系統資源是否吃緊、臨時要記的一句話或一條待辦。
既有做法（開啟瀏覽器分頁、開啟獨立小工具、使用系統內建時鐘）各自零散、且會佔用工作區或被其他視窗遮住。

本專案以「一顆常駐桌面的浮動按鈕 + 一個可展開的資訊面板」整合上述需求，
面板在使用者不互動時**不搶焦點、不干擾輸入**，需要時單擊即可取得資訊。

### 1.2 目標（Goals)

- **G-001** 單擊即可取得日常高頻資訊，無需切換視窗或開啟瀏覽器。
- **G-002** 存在感低、不干擾：平時不搶焦點、可隨時收合、置頂但不阻擋操作。
- **G-003** 資料完全儲存於本機，格式透明可讀，可備份、可手動檢視。
- **G-004** 架構可移植：平台差異集中於抽象層，未來可在不重寫核心邏輯的前提下支援 macOS / Linux。

### 1.3 非目標（Non-Goals，明確排除以避免範圍膨脹）

- **NG-001** 不做雲端同步、使用者帳號、跨裝置資料共享。
- **NG-002** 不做行動裝置（Android / iOS）版本。
- **NG-003** 不保證 Linux Wayland 下的視窗自行定位與強制置頂（屬協定限制）。
- **NG-004** 本階段不實作、不驗證 macOS / Linux；僅保留抽象介面。
- **NG-005** 不做：Markdown 渲染、筆記標籤/分類、待辦到期日/優先級/提醒通知、
  RSS 已讀未讀、RSS 摘要內容、favicon 抓取、全域快速鍵、點擊面板外部自動收合、多實例。
- **NG-006** 不做自動更新機制、不做帳號或付費功能。
- **NG-007** 不做繁體中文以外的實際翻譯（僅抽離字串以保留 i18n 可能性）。
- **NG-008** 不支援需要驗證（帳密）的 RSS 來源。

## 2. 目標使用者

### 2.1 主要使用者

- **U-001 個人電腦工作者**：長時間在單一或少數應用程式間切換，需要快速取得零碎資訊，
  但不想被打斷輸入節奏。
- **U-002 具備基本技術能力的進階使用者**：願意自行編輯本機 JSON 設定檔、
  自行備份資料目錄，且在意資料是否離開本機。

### 2.2 使用者特徵與前提

- 使用 Windows 10 / 11 x64 桌機或筆電，可能有外接螢幕與不同 DPI 縮放。
- 網路可能間歇中斷（RSS 需優雅降級，其餘功能須完全離線可用）。
- 具備本機使用者權限，**不具備**也**不需要**系統管理員權限。
- 同時只會有一位使用者、一個實例（單機單人）。

## 3. 主要目標功能範圍（In Scope / MVP）

本階段交付的核心範圍為下列四大功能群，缺一不可：

### 3.1 浮動入口與資訊面板

- 桌面顯示可自由拖曳的圓形浮動按鈕，嚴格置頂、不佔工作列與 Alt+Tab。
- 點擊按鈕 → 在按鈕下方展開資訊面板；再次點擊、按關閉鈕或 `Esc` → 收合。
- 面板保持在其他一般視窗（含全螢幕應用）上方。
- 面板內容以卡片呈現，卡片可收折與拖曳排序。

### 3.2 時間資訊

- 顯示目前時間與日期（西元 + 星期，不顯示秒）。
- 提供 12 小時制 / 24 小時制切換，選擇持久化。
- 自動更新，不需手動重新整理。

### 3.3 常用網址捷徑

- 顯示使用者設定的常用網站。
- 支援新增、刪除、拖曳排序。
- 點擊後以系統預設瀏覽器開啟。
- 無效或無法開啟的網址不影響其他功能運作。

### 3.4 資訊卡群

- **RSS**：自動讀取多個來源並顯示最新文章（標題 / 來源 / 時間）。
- **系統狀態**：顯示 CPU、記憶體與磁碟使用量。
- **本地筆記**：新增、編輯、搜尋、刪除（純文字）。
- **待辦清單**：建立、完成、刪除、排序。

## 4. 額外目標與延伸功能（Out of MVP Core, In This Release）

### 4.1 本階段交付（對應 X-001~X-008）

以下功能不屬四大核心，但為本次交付範圍的一部分：

- **X-001 系統托盤**：常駐托盤圖示，提供顯示/隱藏、設定、重新整理、開啟資料目錄、退出等操作。
- **X-002 開機自動啟動**：可由設定開啟/關閉（使用者層級，不需管理員權限）。
- **X-003 單一實例**：全系統僅允許一個實例；重複啟動時喚醒既有實例並退出新行程。
- **X-004 獨立設定視窗**：集中管理時間制、面板寬度、按鈕尺寸/透明度、RSS 來源、
  更新頻率、開機自啟、記錄層級、資料/記錄檔入口等。
- **X-005 待辦數量徽章**：浮動按鈕顯示未完成待辦數量。
- **X-006 視覺回饋與動畫**：按鈕懸停/點擊回饋、面板展開收合轉場（可關閉）。
- **X-007 記錄檔與診斷**：輪替式記錄檔，並提供「開啟記錄檔位置 / 開啟資料目錄」入口。
- **X-008 面板內退出程式**：除托盤外，面板亦提供退出動作。

### 4.2 未來延伸（明確不在本階段）

- macOS / Linux（X11）實作；Wayland 降級行為文件化。
- RSS 磁碟快取與離線檢視、已讀狀態、摘要預覽。
- 筆記 Markdown 渲染、標籤分類；待辦到期日、優先級、提醒通知。
- 全域快速鍵、點擊外部自動收合、卡片顯示/隱藏開關、多實例、多語言介面、自動更新。

## 5. 使用者操作流程

### 5.1 UF-001 取得時間與日期

1. 使用者單擊浮動按鈕 → 面板於按鈕下方展開。
2. 時間卡片顯示目前時間與日期；時間持續自動跳動。
3. 使用者可點卡片標題列的切換鈕在 12/24 制間切換，格式立即改變且被記住。
4. 使用者再次單擊按鈕（或按 `Esc`）→ 面板收合。

### 5.2 UF-002 開啟常用網站

1. 使用者展開面板，於捷徑卡片點「新增」，輸入名稱與網址後確認。
2. 點擊該筆捷徑 → 系統預設瀏覽器開啟對應網站。
3. 使用者可用拖曳把手調整捷徑順序；可刪除不需要的捷徑。
4.（例外）若捷徑網址無效或無法開啟，卡片內顯示非阻斷提示，其他功能不受影響。

### 5.3 UF-003 瀏覽 RSS 最新文章

1. 使用者於設定視窗新增一或多個 RSS 來源並啟用。
2. 首次展開面板時觸發抓取；之後每 N 分鐘背景更新（面板收合時暫停）。
3. 卡片依來源顯示最新數篇文章（標題 / 來源 / 時間），新到舊排序。
4. 點擊標題 → 以預設瀏覽器開啟該文章。
5.（例外）某來源逾時或無法解析時，僅該來源顯示錯誤與最後成功時間，其他來源照常。

### 5.4 UF-004 監看系統資源

1. 使用者展開面板 → 系統狀態卡片顯示 CPU、記憶體、磁碟百分比與進度條。
2. 每 2 秒更新一次；超過門檻時顏色改變以示警。
3. 面板收合 → 停止輪詢（節省電力）；再次展開立即取得最新值。

### 5.5 UF-005 記錄筆記

1. 使用者在筆記卡片按「新增」→ 出現就地編輯區（標題 + 多行內文）。
2. 輸入內容後停止輸入約 0.8 秒即自動儲存（或失焦時立即儲存）。
3. 使用者在搜尋框輸入關鍵字 → 清單即時篩選（比對標題與內文）。
4. 使用者選擇筆記 → 就地編輯；按刪除 → 二次確認後刪除。

### 5.6 UF-006 管理待辦

1. 使用者在待辦卡片頂部輸入框輸入內容並按 `Enter` → 建立待辦。
2. 勾選待辦 → 標記完成並下沉至「已完成」區。
3. 未完成項可以拖曳把手調整順序；可一鍵隱藏/顯示已完成項。
4. 浮動按鈕徽章即時反映未完成數量。
5. 刪除待辦 → 直接移除。

### 5.7 UF-007 調整設定與退出

1. 使用者點面板齒輪圖示（或托盤選單「設定」）→ 開啟獨立設定視窗。
2. 變更任一設定即時生效並持久化（不需按確認）。
3. 使用者可由面板內的退出鈕或托盤選單「退出程式」結束應用程式。
4. 使用者可於設定視窗開啟資料目錄或記錄檔位置以便備份/診斷。

### 5.8 UF-008 日常互動（不干擾）

1. 面板未展開時，使用者於其他程式正常輸入，浮動按鈕不搶焦點。
2. 使用者點擊桌面或應用程式視窗（面板以外區域）→ 面板保持展開，不自動收合。
3. 使用者將按鈕拖曳到螢幕邊緣/底部 → 面板自動翻轉方向以避免超出螢幕。

## 6. 功能需求

### FR-001 浮動按鈕（Floating Button）

- **FR-001.1** 應用程式啟動後顯示一顆圓形浮動按鈕；視窗無邊框（frameless）、背景透明、圓角。
- **FR-001.2** 使用者可按住按鈕自由拖曳至桌面任意位置（不限於單一螢幕）。
- **FR-001.3** 按鈕為**嚴格置頂**（strict topmost）：包含全螢幕影片、遊戲、簡報皆保持在最上層。
- **FR-001.4** 按鈕不顯示於工作列，且不出現在 Alt+Tab 清單（Tool window 語意）。
- **FR-001.5** 記住最後位置並持久化；啟動時若座標落在目前已不存在的螢幕或螢幕可見區之外，
  自動修正回主要螢幕的可見區域內。
- **FR-001.6** 設定中提供「重置按鈕位置」動作，還原至主要螢幕預設角落。
- **FR-001.7** 按鈕尺寸與整體透明度可調整（設定中），即時生效並持久化。
- **FR-001.8** 按鈕顯示**未完成待辦數量**徽章；數量為 0 時不顯示徽章。
- **FR-001.9** 滑鼠懸停與點擊需有視覺回饋（縮放/亮度/陰影等輕量動畫），可由設定關閉。
- **FR-001.10** 單擊按鈕切換面板展開/收合（toggle）。
- **FR-001.11** 必須區分「拖曳」與「點擊」：按下後移動超過門檻（4 px）視為拖曳，
  放開時不得觸發展開/收合；未超過門檻才視為點擊。

### FR-002 資訊面板（Panel）

- **FR-002.1** 展開時顯示於按鈕**下方**，水平方向與按鈕對齊（置中）。
- **FR-002.2** 邊界自動翻轉：
  - 按鈕下方空間不足 → 於按鈕**上方**展開；
  - 右側空間不足 → 面板向左貼齊螢幕右緣；
  - 左側空間不足 → 面板向右貼齊螢幕左緣。
- **FR-002.3** 面板**固定寬度**（預設 360 px，可設定）；高度隨內容成長，
  上限為「所在螢幕可用高度 − 按鈕高度 − 間距」；超出上限時面板內部垂直捲動。
- **FR-002.4** 面板與按鈕同為置頂層級，且面板不得遮住按鈕本身。
- **FR-002.5** **焦點策略（點按鈕才聚焦）**：平時浮動按鈕不搶焦點；
  使用者點擊按鈕展開面板後，焦點才轉移至面板（讓使用者可直接在筆記/待辦輸入框打字）。
- **FR-002.6** 收合方式（三者皆可）：再次點擊浮動按鈕、點擊面板上的關閉鈕、按 `Esc`。
- **FR-002.7** **不因點擊面板外部而自動收合**（不實作全域滑鼠監聽）。
- **FR-002.8** 面板內提供「退出程式」動作（與托盤退出等價）。
- **FR-002.9** 展開/收合需有輕量轉場動畫，可由設定關閉（關閉後為即時顯示）。
- **FR-002.10** 按鈕移動、設定變更（寬度/尺寸）或螢幕組態變更時，面板位置重新計算。
- **FR-002.11** 每次啟動時面板預設為**收合**（只顯示按鈕），不自動展開。

### FR-003 卡片系統（Cards）

- **FR-003.1** 提供六張功能卡片：時間、網址捷徑、RSS、系統狀態、筆記、待辦。
- **FR-003.2** 每張卡片可**收折/展開**，狀態持久化。
- **FR-003.3** 卡片可**拖曳排序**：僅在卡片標題列的專用「拖曳把手」上按住拖曳才啟動排序，
  避免與點擊、文字選取、捲動衝突；順序持久化。
- **FR-003.4** **禁止嵌套捲動**：面板本身是唯一的垂直捲動容器，卡片內部不設捲動區。
- **FR-003.5** 內容上限（防止單一卡片撐爆面板高度）：
  - RSS：每個來源顯示最新 N 篇（預設 5，可設定 3–10）。
  - 筆記：未執行搜尋時最多渲染 50 筆（最近更新優先）；超過時顯示提示
    「僅顯示前 50 筆，請使用搜尋」。
  - 待辦：不設渲染上限，但完成項可一鍵隱藏。
- **FR-003.6** 卡片標題列固定顯示名稱與收折箭頭；可依需要放置卡片層級小型操作鈕
  （例如時間卡的 12/24 切換、RSS 的重新整理）。
- **FR-003.7** 卡片順序與收折狀態變更後立即持久化（不需按儲存）。
- **FR-003.8** 卡片為「唯讀呈現 + 就地編輯」混合；高度由內容決定，不設固定高度。
- **FR-003.9** **不提供**卡片顯示/隱藏開關；六張卡片固定存在，僅能收折與排序。

### FR-004 時間資訊卡

- **FR-004.1** 顯示目前時間，**不顯示秒數**，格式依 12/24 制設定：
  - 24 制：`HH:mm`（例：`14:05`）
  - 12 制：`hh:mm AM/PM`（例：`02:05 PM`）
- **FR-004.2** 顯示日期與星期，格式為西元：`YYYY/MM/DD 星期X`（例：`2026/09/28 星期一`）。
- **FR-004.3** 提供 **12 小時制 / 24 小時制切換**（卡片標題列切換鈕），選擇持久化。
- **FR-004.4** 時間**自動更新**，不需使用者手動重整；顯示須即時正確（不需顯示秒數，
  但分鐘變化必須反映）。
- **FR-004.5** 時間與日期須反映系統時間變更（時區調整、手動改時間）而不需重啟程式。

### FR-005 常用網址捷徑卡

- **FR-005.1** 以**垂直清單**呈現，每列顯示名稱 + 網址；使用預設圖示（不抓取 favicon）。
- **FR-005.2** 支援**新增、刪除、拖曳排序**（使用專用拖曳把手，與卡片排序一致）。
- **FR-005.3** 點擊捷徑以**系統預設瀏覽器**開啟（經平台抽象層；Windows 使用 `os.startfile` / `webbrowser`）。
- **FR-005.4** **輸入正規化**：自動去除前後空白；若無 scheme 則自動補上 `https://`。
- **FR-005.5** **輸入驗證**：網址為空，或明顯不合法（例如缺少 host、含有空白字元）時，
  於輸入區顯示行內提示並**不允許儲存**；其餘輸入一律接受。
- **FR-005.6** **無效或無法開啟的網址不得影響其他功能**：
  - 點擊後開啟失敗時，僅在卡片內顯示非阻斷錯誤提示（例：「無法開啟此網址」）；
  - 不得拋出未處理例外、不得凍結 UI、不得中斷 RSS / 系統狀態 / 筆記 / 待辦。
- **FR-005.7** 名稱為空時以網址作為顯示名稱。
- **FR-005.8** 刪除捷徑直接執行（低風險，不跳確認框）。

### FR-006 RSS 卡

- **FR-006.1** 支援**多個來源**；每個來源具：名稱、URL、啟用/停用、排序。
- **FR-006.2** **定時背景更新**：預設每 30 分鐘抓取一次（可設定 5–180 分鐘）。
- **FR-006.3** 面板展開時，若快取已過期或從未抓取，立即觸發一次抓取。
- **FR-006.4** 卡片提供**手動重新整理**按鈕。
- **FR-006.5** 面板**收合時暫停**定時抓取；重新展開時恢復並視需要刷新。
- **FR-006.6** 每篇文章顯示：**標題 + 來源名稱 + 發佈時間**；點擊以預設瀏覽器開啟連結。
- **FR-006.7** 每個來源顯示最新 N 篇（預設 5，可設定 3–10），依發佈時間新→舊排序；
  無發佈時間者依 feed 原順序排在最後。
- **FR-006.8** **失敗隔離**：單一來源失敗不影響其他來源，也不影響其他卡片；
  該來源顯示錯誤提示與「最後成功更新時間」。
- **FR-006.9** 網路抓取須設逾時（預設 10 秒）與 User-Agent；不得因逾時阻塞 UI。
- **FR-006.10** 不實作已讀/未讀狀態；**不快取至磁碟**（僅記憶體快取，重啟後重新抓取）。
- **FR-006.11** 不渲染 feed 提供的 HTML/摘要內容（僅顯示純文字標題，避免注入與外部資源載入）。
- **FR-006.12** 所有網路 I/O 於背景執行緒執行，結果以訊號回主執行緒更新 UI。

### FR-007 系統狀態卡

- **FR-007.1** 顯示：CPU 總使用率、記憶體使用率（含 used / total）、磁碟使用率。
- **FR-007.2** 每項顯示**百分比數字 + 進度條**。
- **FR-007.3** 更新頻率預設 **2 秒**（可設定 1 / 2 / 5 秒）。
- **FR-007.4** **超閾值變色**，門檻為**固定預設值**（不開放設定）：
  - < 70%：一般色
  - 70%–89%：警告色
  - ≥ 90%：危險色
- **FR-007.5** 磁碟**只列出本機固定磁碟**，排除抽取式（USB / 讀卡機）與網路磁碟。
- **FR-007.6** 磁碟項目顯示：磁碟代號 / 掛載點 + 使用百分比。
- **FR-007.7** **查詢例外不得中斷程式**：單一項目查詢失敗顯示 `N/A` 並記錄 log。
- **FR-007.8** 面板**收合時暫停輪詢**；展開時立即取得一次最新值。
- **FR-007.9** 所有 psutil 查詢於**背景執行緒**執行（磁碟查詢在部分環境可能阻塞數秒），不得阻塞 UI。

### FR-008 本地筆記卡

- **FR-008.1** 欄位：標題、內文（純文字）、建立時間、更新時間。**不支援 Markdown 渲染**。
- **FR-008.2** 支援**新增、編輯、刪除、搜尋**。
- **FR-008.3** **即時搜尋**：輸入關鍵字即時篩選，比對**標題與內文**，不分大小寫。
- **FR-008.4** **自動儲存**：編輯後 debounce（約 800 ms）即存，或於失焦時立即儲存；
  不需按「儲存」；狀態改變立即持久化。
- **FR-008.5** 就地編輯：於筆記卡片內展開編輯區（標題 + 多行內文），不另開視窗。
- **FR-008.6** 刪除**需二次確認**（筆記內容不可逆）。
- **FR-008.7** 預設清單排序為**最近更新優先**。
- **FR-008.8** 標題留空時自動以內文首行為標題；仍留空則顯示「未命名」。
- **FR-008.9** 標題與內文皆為空的新增筆記不儲存（自動捨棄），避免產生空資料。
- **FR-008.10** 搜尋輸入不得因頻繁重繪而卡頓（清單更新須增量且節流）。

### FR-009 待辦清單卡

- **FR-009.1** 欄位：內容文字、完成狀態、排序值、建立時間、完成時間。
- **FR-009.2** 支援**建立、勾選完成、取消完成、刪除、拖曳排序**。
- **FR-009.3** 清單分兩區：**未完成**（上）、**已完成**（下）。
- **FR-009.4** **完成項自動下沉**至已完成區，依完成時間新→舊排列。
- **FR-009.5** 可一鍵**隱藏/顯示已完成項**，偏好持久化。
- **FR-009.6** 未完成區支援**手動拖曳排序**（使用專用拖曳把手）。
- **FR-009.7** 快速新增：卡片頂部輸入框按 `Enter` 建立；輸入為空或僅空白則不建立。
- **FR-009.8** 刪除待辦直接執行（低風險）。
- **FR-009.9** **不支援**到期日、優先級、標籤、提醒通知。
- **FR-009.10** 未完成數量變動時，即時更新浮動按鈕徽章數字。

### FR-010 設定視窗

- **FR-010.1** **獨立視窗**，由面板齒輪圖示或托盤選單開啟。
- **FR-010.2** 設定項目至少包含：
  - 時間制（12 / 24 小時）
  - 面板寬度
  - 系統狀態更新頻率（1 / 2 / 5 秒）
  - RSS 來源管理（新增 / 編輯 / 刪除 / 啟用 / 排序）＋ 更新間隔 ＋ 每來源顯示篇數
  - 按鈕尺寸與透明度
  - 開機自動啟動開關
  - 重置按鈕位置
  - 顯示 / 隱藏已完成待辦
  - 動畫開關
  - 記錄層級（INFO / DEBUG）
  - 「開啟資料目錄」與「開啟記錄檔位置」
- **FR-010.3** 設定變更**即時生效**並持久化（不需按確定）。
- **FR-010.4** 設定視窗為**模態單一視窗**（不得同時開啟多個）。
- **FR-010.5** 開啟或關閉設定視窗不得改變面板展開狀態或卡片狀態。
- **FR-010.6** 非法輸入（例如寬度超界）自動夾限至合法範圍。

### FR-011 系統托盤

- **FR-011.1** 常駐系統托盤圖示，具 tooltip。
- **FR-011.2** 右鍵選單：顯示/隱藏浮動按鈕、顯示/隱藏面板、設定、
  立即重新整理（RSS + 系統狀態）、開啟資料目錄、開啟記錄檔位置、關於、退出程式。
- **FR-011.3** 雙擊托盤圖示切換面板顯示。
- **FR-011.4** 若托盤不可用（極少數環境），程式仍必須可用；退出改由面板內的退出鈕執行。

### FR-012 開機自動啟動

- **FR-012.1** 設定中提供開機自動啟動開關，預設為**關閉**。
- **FR-012.2** Windows 實作於**使用者層級**（登錄檔 `HKCU\...\Run` 或使用者啟動資料夾捷徑），
  不需系統管理員權限。
- **FR-012.3** 關閉開關時必須完整移除對應項目。
- **FR-012.4** 開發模式（以 `python -m` 執行）與打包模式（exe）皆須能正確登錄啟動指令。
- **FR-012.5** 平台差異以抽象介面隔離（macOS LaunchAgent / Linux `.desktop` autostart 僅保留介面，不實作）。

### FR-013 單一實例

- **FR-013.1** 全系統僅允許一個應用程式實例（具名 mutex / 鎖）。
- **FR-013.2** 使用者再次啟動時，偵測到既有實例 → 將現有按鈕與面板帶到前景 → 新行程立即退出。
- **FR-013.3** 資料檔僅由單一實例讀寫，避免多寫入者造成資料損毀。

### FR-014 資料儲存

- **FR-014.1** 資料存放於標準使用者資料目錄（`platformdirs`）。
- **FR-014.2** 每個檔案含 `schema_version` 欄位，供未來遷移使用。
- **FR-014.3** **原子寫入**：先寫暫存檔再原子置換，避免寫入中斷造成損毀。
- **FR-014.4** **JSON 損毀復原**：解析失敗時將原檔改名為 `<name>.corrupt-<timestamp>`、
  以預設值重建、記錄 log，並於 UI 顯示非阻斷提示。
- **FR-014.5** 任一資料檔讀取失敗**不得阻止程式啟動**（以預設值繼續）。
- **FR-014.6** 寫入失敗（權限不足、磁碟滿）時記錄 log 並顯示非阻斷提示，不得崩潰。
- **FR-014.7** 資料檔為人類可讀 JSON（縮排），利於備份與手動檢視。

### FR-015 記錄與錯誤處理

- **FR-015.1** 使用輪替式記錄檔（單檔上限 1 MB，保留 3 份）。
- **FR-015.2** 記錄層級可設定（預設 INFO / 可切 DEBUG）。
- **FR-015.3** 所有預期錯誤（RSS 逾時 / DNS / 非 XML、psutil 例外、JSON 損毀、
  開啟瀏覽器失敗、無效網址）都必須同時具備：**卡片內友善提示** 與 **log 記錄**。
- **FR-015.4** 未捕捉例外由全域例外鉤子記錄至 log；**不彈出對話框**。
- **FR-015.5** 提供「開啟記錄檔位置」與「開啟資料目錄」入口（設定視窗 + 托盤選單）。
- **FR-015.6** log 不得記錄任何敏感資訊（本專案預期無憑證；RSS URL 可記錄）。

## 7. 非功能需求

- **NFR-001 效能（閒置）**：面板收合、僅顯示浮動按鈕時，CPU 平均使用率 < 1%。
- **NFR-002 效能（展開）**：面板展開且系統狀態輪詢中，CPU 平均使用率 < 5%（不含 RSS 抓取瞬間）。
- **NFR-003 記憶體**：常態常駐記憶體（RSS）< 200 MB。
- **NFR-004 啟動時間**：`onedir` 打包後冷啟動 < 3 秒。
- **NFR-005 不得阻塞 UI**：所有網路 I/O 與 psutil 查詢必須於背景執行緒執行；
  主執行緒僅進行 UI 更新。
- **NFR-006 跨平台架構**：平台差異集中於 `platform_api/` 抽象層
  （**不可命名為 `platform/`**，會遮蔽 Python 標準庫 `platform` 模組並使 pytest 無法執行，見附錄 D D-000）；
  `core/` 不得直接呼叫平台專屬 API。
- **NFR-007 高 DPI**：支援 Windows 縮放 100%–200%，文字與圖示不得模糊。
- **NFR-008 多螢幕**：支援多螢幕與混合 DPI；位置計算一律以 `QScreen.availableGeometry` 為準。
- **NFR-009 平台相容**：Windows 10 / 11 x64、Python 3.11+。
- **NFR-010 依賴最小化**：執行期僅 `PySide6`、`psutil`、`feedparser`、`httpx`、`platformdirs`
  （＋測試用 `pytest`、`pytest-qt`）。
- **NFR-011 可測試性**：核心邏輯與 UI 解耦；邏輯層須能在無 GUI 環境下單元測試。
- **NFR-012 離線優雅降級**：無網路時，時間 / 捷徑 / 筆記 / 待辦 / 系統狀態全部正常運作；
  RSS 顯示錯誤與最後成功更新時間。
- **NFR-013 隱私**：除使用者設定的 RSS 來源外不進行任何對外連線；無 telemetry、無帳號。
- **NFR-014 權限**：不需系統管理員權限即可安裝與執行。
- **NFR-015 韌性**：任何單一功能失敗不得導致應用程式整體崩潰或無法啟動。
- **NFR-016 資料安全**：原子寫入 + 損毀備份，避免使用者資料遺失。
- **NFR-017 資源節省**：面板收合時暫停系統狀態輪詢與 RSS 定時抓取。
- **NFR-018 可維護性**：平台差異以抽象介面隔離；新增平台不得修改 `core/` 邏輯。

## 8. 技術架構

### 8.1 技術選型

| 層面 | 選擇 | 理由 |
| --- | --- | --- |
| 語言 | Python 3.11+ | 跨平台、生態完整、開發效率高 |
| GUI | PySide6（Qt 6） | 無邊框 + 透明 + 圓角 + 置頂 + QSS + 高 DPI 支援最完整；LGPL 動態連結可用 |
| 系統資訊 | `psutil` | 跨平台取得 CPU / 記憶體 / 磁碟資訊 |
| RSS 解析 | `feedparser` | 成熟穩定的 feed 解析 |
| HTTP | `httpx` | 逾時控制與測試替換容易 |
| 路徑 | `platformdirs` | 各平台標準使用者資料/設定目錄 |
| 測試 | `pytest` + `pytest-qt` | 邏輯層 + Qt 元件測試 |
| 打包 | PyInstaller `onedir` | 啟動快、除錯容易、防毒誤判較少 |

### 8.2 模組分層

```text
app.py                       # 組裝與啟動（建立 QApplication、單一實例、托盤、按鈕）
pyproject.toml               # 專案與依賴宣告（Python 3.11+ 與依賴）
requirements.txt             # 依賴清單（與 pyproject 擇一為準或保持同步）
assets/                      # 圖示資源（托盤 .ico、按鈕圖示、執行檔 icon）
tests/                       # pytest 單元測試 + pytest-qt 元件測試
core/                        # 不含 Qt，可在無 GUI 環境完整單元測試
  models.py                  # Note / Todo / Shortcut / Feed / AppConfig 資料模型
  storage.py                 # JSON 原子讀寫、schema_version、損毀復原
  settings.py                # 設定讀寫、範圍驗證與夾限
  shortcuts.py               # 網址正規化/驗證
  rss.py                     # feed 抓取與解析（fetcher 以注入方式提供，便於 mock）
  system.py                  # psutil 查詢封裝（以注入方式提供，便於 mock）
  search.py                  # 筆記搜尋
  orders.py                  # 排序（卡片順序、捷徑、待辦）
  logging_setup.py           # 輪替式記錄檔、日誌層級、全域例外鉤子
ui/                          # PySide6 專屬
  floating_button.py         # 浮動按鈕視窗（拖曳/點擊判定、徽章、動畫）
  panel.py                   # 面板視窗（定位/翻轉、單一捲動容器）
  cards/                     # 六種卡片（clock / shortcuts / rss / system / notes / todos）
  settings_window.py         # 獨立設定視窗
  tray.py                    # 系統托盤
  theme.py                   # QSS、色彩、閾值色
  strings.py                 # 繁體中文字串表（僅抽離、不翻譯；C-006）
platform_api/                # 平台抽象（Windows 實作 + 其他平台 stub）
                             # 注意：不可命名為 platform/，會遮蔽 Python 標準庫 platform 模組
  window_flags.py            # 嚴格置頂、不顯示於工作列
  autostart.py               # 開機自動啟動
  single_instance.py         # 單一實例鎖
  browser.py                 # 開啟預設瀏覽器
  paths.py                   # 資料/記錄路徑、開啟資料夾
```

### 8.3 執行緒模型

- **主執行緒**：僅處理 Qt UI。
- **背景工作**：以 `QThreadPool` + `QRunnable`（或 QThread worker）執行
  RSS 抓取、psutil 輪詢、磁碟查詢。
- **結果回傳**：worker 一律以 Qt signal 回傳，UI 元件不得於 worker 執行緒被存取。
- **定時器**：時間卡每秒；系統狀態每 2 秒（可設定）；RSS 每 N 分鐘。
  面板收合時暫停「系統狀態」與「RSS」定時器（NFR-017）。

### 8.4 技術約束

- **C-001** 只實作與驗證 Windows；macOS / Linux 僅保留架構抽象。
- **C-002** 不使用需要**全域滑鼠/鍵盤 hook** 的機制（故不做點擊外部收合、不做全域快速鍵）。
- **C-003** Linux Wayland 無法由應用程式自行定位視窗或強制置頂，屬已知平台限制（文件須註明）。
- **C-004** PySide6 為 LGPL，採動態連結並保留授權聲明。
- **C-005** 打包使用 PyInstaller `onedir`。
- **C-006** 介面文字為繁體中文，但字串須抽離以保留 i18n 可能性。
- **C-007** 專案已納入 Git 版控（origin：`https://github.com/DunkLiao/py_assistant_desktop.git`，
  預設分支 `main`）。未經使用者明確授權，不執行 `push --force`、歷史改寫
  （`rebase` / `reset --hard`）或破壞性清理（`clean -fd`）。

## 9. 資料保存方式

### 9.1 儲存位置

使用 `platformdirs` 取得標準使用者資料目錄下的應用程式專屬子目錄
（Windows 對應 `%LOCALAPPDATA%\<AppName>`）。
不使用程式安裝目錄，避免權限問題；不提供可攜模式（見 NG-005）。

### 9.2 檔案清單與格式

`config.json` — 應用程式設定：

```json
{
  "schema_version": 1,
  "time_format": "24h",
  "panel_width": 360,
  "system_poll_interval_sec": 2,
  "rss_refresh_interval_min": 30,
  "rss_max_items_per_feed": 5,
  "button": { "size": 56, "opacity": 1.0, "x": 1600, "y": 900, "screen_name": "\\\\.\\DISPLAY1" },
  "autostart": false,
  "show_completed_todos": true,
  "animation_enabled": true,
  "log_level": "INFO"
}
```

`ui_state.json` — UI 狀態：

```json
{
  "schema_version": 1,
  "card_order": ["clock", "shortcuts", "rss", "system", "notes", "todos"],
  "card_collapsed": {
    "clock": false, "shortcuts": false, "rss": false,
    "system": false, "notes": false, "todos": false
  }
}
```

`shortcuts.json` — 網址捷徑：

```json
{ "schema_version": 1,
  "items": [ { "id": "uuid", "name": "信箱", "url": "https://mail.example.com", "order": 0 } ] }
```

`feeds.json` — RSS 來源：

```json
{ "schema_version": 1,
  "items": [ { "id": "uuid", "title": "來源名稱", "url": "https://example.com/feed.xml",
               "enabled": true, "order": 0 } ] }
```

`notes.json` — 筆記：

```json
{ "schema_version": 1,
  "items": [ { "id": "uuid", "title": "", "body": "",
               "created_at": "ISO-8601", "updated_at": "ISO-8601" } ] }
```

`todos.json` — 待辦：

```json
{ "schema_version": 1,
  "items": [ { "id": "uuid", "text": "", "done": false, "order": 0,
               "created_at": "ISO-8601", "completed_at": null } ] }
```

`app.log` — 輪替式記錄檔（1 MB × 3）。

### 9.3 讀寫規則

- 所有寫入採**原子寫入**（寫入暫存檔 → 原子置換），避免中斷造成損毀（FR-014.3）。
- 解析失敗 → 原檔改名為 `<name>.corrupt-<timestamp>`、以預設值重建、記 log、UI 非阻斷提示（FR-014.4）。
- 缺檔視為首次啟動，以預設值建立（不視為錯誤）。
- 讀取失敗不得阻止程式啟動（FR-014.5）。
- 寫入失敗記錄 log 並提示，資料保留於記憶體待下次重試（FR-014.6）。
- RSS 內容**不落地**：僅記憶體快取，重啟後重新抓取（FR-006.10）。
- 資料不加密（明碼 JSON），此為已知且接受的取捨（見 SEC-007）。

## 10. 安全與權限邊界

- **SEC-001** 所有資料僅儲存於本機使用者資料目錄；無雲端、無帳號、無 telemetry。
- **SEC-002** 除使用者設定的 RSS URL 外，不進行任何對外網路連線。
- **SEC-003** 不渲染 RSS 提供的 HTML 內容（僅顯示純文字標題），避免注入與外部資源載入。
- **SEC-004** 不儲存任何密碼或憑證；需要驗證的 RSS 來源不支援（NG-008）。
- **SEC-005** log 不記錄敏感資料。
- **SEC-006** 開機自啟僅寫入使用者層級位置，不需系統管理員權限。
- **SEC-007** 資料為本機明碼 JSON，明確告知使用者非加密儲存。
- **SEC-008** 單一實例鎖避免多寫入者造成資料損毀。
- **SEC-009** 權限邊界：程式僅在使用者權限下執行；不提升權限、不修改系統層級設定。
- **SEC-010** 不執行來自外部（RSS feed / 使用者輸入）的任何程式碼或指令；
  開啟捷徑/文章一律交由系統預設瀏覽器處理。

## 11. 錯誤與降級行為

| 編號 | 情境 | 行為 |
| --- | --- | --- |
| EH-001 | RSS 連線逾時 / DNS 失敗 | 該來源顯示錯誤 + 最後成功時間；log WARNING；不影響其他來源/卡片 |
| EH-002 | RSS 回傳非 XML / 解析失敗 | 同上，訊息標示「無法解析此來源」 |
| EH-003 | 系統狀態查詢例外 | 該項目顯示 `N/A`；log WARNING；其他項目照常 |
| EH-004 | 磁碟查詢阻塞 | 於背景執行緒執行；UI 顯示載入中，不凍結 |
| EH-005 | JSON 損毀 | 改名為 `.corrupt-<timestamp>`、以預設值重建、log ERROR、UI 非阻斷提示 |
| EH-006 | JSON 寫入失敗（權限/空間） | log ERROR + 非阻斷提示；資料保留於記憶體，下次寫入重試 |
| EH-007 | 開啟瀏覽器失敗 | 卡片內非阻斷提示；log WARNING |
| EH-008 | 使用者輸入無效網址 | 輸入時行內提示且不儲存；已存在資料的開啟失敗則卡片提示 |
| EH-009 | 螢幕被拔除 / 解析度變更 | 重算面板位置；按鈕移回可見區 |
| EH-010 | 單一實例鎖取得失敗 | 喚醒既有實例後退出（屬正常路徑，非錯誤） |
| EH-011 | 托盤不可用 | 程式照常運作；退出改由面板退出鈕（FR-011.4） |
| EH-012 | 設定值非法 | 自動夾限至合法範圍並持久化（FR-010.6） |
| EH-013 | 未捕捉例外 | 全域鉤子寫入 log；不彈窗（FR-015.4） |
| EH-014 | 無網路 | 本地功能全部正常；RSS 顯示錯誤與最後更新時間（NFR-012） |
| EH-015 | 資料目錄不可寫 | log ERROR + 提示；程式以記憶體模式運作，不崩潰 |

**降級原則**：任一功能失敗僅影響該功能本身的資料呈現，不得擴散至其他卡片，
亦不得阻止應用程式啟動或運作（NFR-015）。

## 13. E2E 測試範圍

### 13.1 測試層次

| 層次 | 工具 | 範圍 |
| --- | --- | --- |
| 單元測試 | `pytest`（無 GUI） | `core/` 全部邏輯：儲存、搜尋、排序、RSS 解析、設定夾限、網址正規化 |
| 元件測試 | `pytest-qt` | 按鈕互動、面板定位、卡片收折/排序、時間格式、筆記 debounce、待辦操作 |
| 端對端（手動） | 人工操作 | 需要真實桌面/系統整合、無法自動化的情境 |
| 打包驗證 | 人工 | `onedir` 產物啟動、托盤、開機自啟、單一實例 |

**自動化邊界**：網路與 psutil 一律以注入替身（fake fetcher / fake system provider）隔離，
測試不得連網、不得依賴機器真實負載。

### 13.2 端對端情境（E2E）

- **E2E-004（AC-007/008）** 面板未展開時於其他程式輸入不受干擾；
  點擊面板外部區域面板不自動收合。
- **E2E-005（AC-010/011）** 收折全部卡片並重排順序 → 重啟 → 狀態與順序一致。
- **E2E-006（AC-012/013）** 觀察時間自動跳動 → 切換 12/24 制 → 重啟 → 選擇保留。
- **E2E-007（AC-014/015/016）** 新增多筆捷徑 → 排序 → 點擊開啟正確網站 →

- **E2E-008（AC-017/018/019）** 設定多來源（正常 + 逾時 + 非 XML）→
  正常來源顯示文章、失敗來源顯示錯誤與最後更新時間 → 收合面板期間無抓取（log 驗證）→
  展開後恢復並刷新。
- **E2E-009（AC-020/021/022）** 系統狀態顯示數值與進度條、超閾值變色 →
  收合後停止更新 → 插入 USB 後磁碟清單不含抽取式磁碟。
- **E2E-010（AC-023/024/025）** 新增筆記 → 輸入後自動儲存 → 重啟後仍在 →

- **E2E-011（AC-004/026/027）** 新增待辦 → 勾選完成下沉 → 取消完成回上層 →
  拖曳排序 → 隱藏完成項 → 徽章數量正確。
- **E2E-012（AC-028）** 開啟設定視窗 → 變更項目即時生效 → 重啟後保留 →
  嘗試再次開啟不產生第二個視窗。
- **E2E-013（AC-029）** 托盤圖示存在 → 右鍵選單各動作有效 → 雙擊切換面板。
- **E2E-014（AC-030）** 開啟自動啟動 → 檢查登錄檔/啟動項目存在 →
  關閉後項目被移除。
- **E2E-015（AC-031）** 已有一個實例時再次啟動 → 只有一顆按鈕 → 既有面板被帶到前景。
- **E2E-016（AC-032/033/035）** 損毀 JSON 後啟動可正常運作並產生 `.corrupt-*` →
  `app.log` 有記錄且可從設定開啟 → 拔除網路後本地功能正常。
- **E2E-017（AC-034/036/038/039/040）** 抓取期間 UI 不凍結 → 閒置 CPU < 1% →
  打包後冷啟動 < 3 秒 → 記憶體 < 200 MB → 未安裝全域 hook。
- **E2E-018（AC-041/042/043/044/045）** 執行位置重置 → 按鈕回到主要螢幕右上角 →
  調整按鈕尺寸與透明度立即生效且重啟後保留 → 懸停/點擊有視覺回饋 →
  關閉動畫後面板為即時展開/收合 → 點面板內退出鈕可結束程式。
- **E2E-019（AC-046/047/048/049/051/052/053/054）** 執行中變更系統時間後時間卡立即反映 →
  只填內文的新筆記以首行為標題 → 全空筆記不被建立 → 空白待辦不被建立 →

  觸發未捕捉例外時寫入 log 且不彈窗 → log 不含敏感資料。
